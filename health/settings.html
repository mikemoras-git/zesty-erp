🔒 Where this data lives
Everything you enter — readings, appointments, lab values and scanned documents — is stored only in this browser, on this device. It is never uploaded, and no one else can read it. That also means nothing is recoverable if this browser's data is cleared, the device is lost, or you use private/incognito mode. Export a backup regularly and keep the file somewhere you trust.
